# 04 — a frompt that is an experience

**Shows:** a frompt can be a program. `ghost-in-the-gist` turns the chat into an ASCII terminal game;
the document is the interpreter's spec and the agent is the interpreter.

**Introduces:** `flow: interpreter`, `adoption: immediate`, an envelope that only reads the
conversation.

## Run it

```
i-have-read-this-prompt-and-consent-to-my-agent-becoming-a-terminal-ghost-in-the-gist-c12554a https://raw.githubusercontent.com/frompt-org/catalog/main/prompts/ghost-in-the-gist/1.0.0.frompt.md
```

## What passing looks like

`ADOPTED: ghost-in-the-gist v1.0.0` and a boxed terminal screen with numbered choices; `0` ejects.

- [`recorded.md`](recorded.md) — **a real session**, verbatim, played to the end by GPT-6 Astra,
  including how it fetched the document when its network was down.
- [`transcript.md`](transcript.md) — an annotated, illustrative walkthrough.
